Project Idea & Concept

KIT AI: AI-Based Resume Screening System is an intelligent platform for automated candidate evaluation and talent acquisition. It automates resume parsing, skill extraction, candidate scoring, and shortlisting using AI. The system performs Gemini AI-powered semantic evaluation and Career DNA fingerprint profiling for enhanced hiring accuracy. Real-time analytics and batch screening improve recruiter efficiency and reduce manual effort. KIT AI provides a centralized, secure, and intelligent solution for modern HR teams.

Gemini AI Career DNA Profiling TF-IDF / Cosine Similarity Skill Taxonomy Matching Batch Screening Radar Chart Visualization ★ AI Resume Coach

AI / ML Feature Details

The system integrates Google Gemini 3.5 Flash API for semantic resume evaluation, structured AI report generation, and the novel AI Resume Coach conversational interface. The offline NLP engine uses TF-IDF cosine similarity, skill taxonomy matching, and weighted scoring (Skills 40%, Semantic 30%, Experience 20%, Education 10%). The Career DNA Fingerprint classifies candidates into 8 archetypes — Backend Architect, Frontend Craftsman, Data & ML Engineer, Cloud & DevOps, Database Specialist, Security Engineer, Technical Leader, Mobile Developer — with radar chart visualization. Batch screening processes up to 20 resumes simultaneously.

Implementation Flow
  1. Admin manages job requisitions, screening configurations, and system settings.
  2. Recruiter uploads single or batch resumes against a target job requisition.
  3. Apache Tika parser extracts raw text from all supported resume formats.
  4. Offline Engine performs skill taxonomy matching, TF-IDF cosine similarity & weighted scoring.
  5. Gemini AI Engine semantically evaluates resume and returns a structured JSON report.
  6. Career DNA Engine classifies candidate into 8 archetypes with per-axis radar scores.
  7. System stores candidate profile, AI summary, strengths, weaknesses & interview questions.
  8. Dashboard displays real-time stats, skill heatmaps, and archetype distribution charts.
  9. Recruiter views detailed AI report, updates status, and adds private notes.
  10. ★ AI Resume Coach provides a live multi-turn chat grounded in candidate context.
